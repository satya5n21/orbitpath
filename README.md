# OrbitPath — AI-Powered Interactive Roadmap Builder

> "Turn your next big goal into small steps you can actually finish."

OrbitPath transforms ambitious technical or personal goals into four distinct, actionable roadmap strategies (`Balanced Path`, `Fast Track`, `Deep Mastery`, and `Tiny Steps`) or lets you build a custom sequence manually.
